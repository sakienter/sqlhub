大会概要とルール

日程
2026年11月20日（金）21:00
定員
8名 定員超過の場合は抽選

ルール

  • 無神祇卓・クトゥーン卓・ヤシャ卓を各1試合、計3試合行い、合計順位ポイントを競います。
  • 順位ポイント：1位 9pt / 2位 7pt / 3位 6pt / 4位 5pt / 5位 4pt / 6位 3pt / 7位 2pt / 8位 1pt
  • 参加者8名の投票で「勝負卓」を決定。勝負卓では獲得する順位ポイントが2倍になります。
  • 勝負卓は1試合目の開始前に公開します。同票の場合は、同票の候補から無作為に選出します。

ゲームのシステム上、コンシードで調整して該当する試合を行います。そのため通常より手順が多く、終了時間が前後する場合があります。ご理解とご協力をお願いいたします。

賞金：1位 3,000円 / 2位 1,000円 / ボーナス 1,000円

ボーナスは、自身が投票した勝負卓が採用され、その卓で1位を獲得した場合に贈られます。
