# Season 2 構成画像

各DAYのJPG画像を次の場所へ配置します。

```text
public/season2/compositions/
├── day1/
├── day2/
├── day3/
└── day4/
```

英数字の選手名は、小文字・記号なしのファイル名を使用します。

例：

```text
Alutemu    -> alutemu.jpg
MATSURI    -> matsuri.jpg
SeseiSei   -> seseisei.jpg
```

日本語名の選手は、サイト側に個別の英字ファイル名を追加するまでは、表示名と同じファイル名でも認識します。

例：DAY1の選手画像は `public/season2/compositions/day1/選手名.jpg` に配置します。

画像がまだ存在しない場合、サイトには「構成画像はまだ登録されていません」と表示されます。
