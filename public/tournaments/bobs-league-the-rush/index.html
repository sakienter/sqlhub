THE RUSH

日本勢向け情報まとめ

大会進行・進出ルート

公式ルール v0.9（2026年7月31日）と公式イベントページをもとに、日本勢向けに要点を整理しています。日時は公式イベントページの最新表示を優先しています。

  1. 01

    Rush（ラダー）

    EU・NA・APACの3地域で同時開催されます。各地域のラダー1位は準決勝へ直接進出し、2〜9位は各地域のClosed Qualifierへ進みます。

    公式開催時間
    8月4日 19:00〜8月10日 21:00（CEST）
    日本時間
    8月5日 2:00〜8月11日 4:00（JST）
  2. 02

    Closed Qualifier（招待予選）

    各地域のRushで2〜9位となった8名が参加します。各地域の優勝者1名が準決勝へ進出します。APACは8月13日、NAは8月12日、EUは8月14日に開催予定です。

  3. 03

    Open Qualifier（一般予選）

    誰でも参加できる一般予選をNA・APAC・EUの各サーバーで1回ずつ開催します。各予選の上位3名が準決勝へ進出し、EU予選のみ上位4名が進出します。

  4. 04

    Semi-finals（準決勝）

    日本時間8月21日・22日の21:00に開催。各準決勝は5試合の累計ポイント制で、各卓の上位4名、合計8名がGrand Finalへ進出します。

  5. 05

    Grand Final（決勝）

    日本時間8月23日 21:00に開催。20ポイントのMatch Point（チェック）ルールで、20ポイント以上に到達した後の試合で1位を獲得した選手が優勝です。勝者が決まるまで試合を続けます。

参加条件

  • Bob's League公式サイトのアカウントと公式Discordへの参加が必要です。
  • THE RUSHの大会エントリー締切は、2026年8月8日（土）6:00（JST）＝8月7日（金）23:00（UTC+2）です。締切までに登録していない選手は、ラダー上位に入っても予選通過できません。ラダー順位確定期限とは別の締切です。
  • 対象大会への登録と、必要な大会ではチェックインを完了してください。
  • 公式大会への出場停止処分を受けていないこと、最新バージョンのゲームを使用できることが条件です。
  • 賞金の受領には、EUからの送金を受け取れる銀行口座が必要です。
大会形式・重要ルール

Closed Qualifier・Open Qualifier・準決勝

順位ポイント：1位 10pt / 2位 8pt / 3位 7pt / 4位 6pt / 5位 4pt / 6位 3pt / 7位 2pt / 8位 1pt

同時落ちは該当順位のポイントを平均して配分します。全試合終了時に完全同点の場合は、直前の試合でより上位だった選手を上位とします。

Grand Final

順位ポイント：1位 7pt / 2位 6pt / 3位 5pt / 4位 4pt / 5位 3pt / 6位 2pt / 7位 1pt / 8位 0pt

20ポイント以上に到達後、次以降の試合で1位を獲得すると優勝です。同時落ちも考慮されます。

プレイ時の注意

  • Rushのラダー結果はHearthstone Deck Trackerで自動送信するか、Bob's Leagueのアカウントから手動登録します。
  • 試合中の口頭・文章による情報共有は禁止です。ゲーム内エモートのみ使用できます。
  • ウィントレード、配信スナイプは禁止です。主催・指定配信者による観戦を許可してください。
  • 5分を超える遅刻は、その試合8位扱いおよび失格の可能性があります。
  • 問題がターン2より前に発生した場合は担当管理者へ連絡してください。試合がリセットされる場合があります。
