大会概要とルール

バトグラ頂上戦は、ハースストーン・バトルグラウンドの大会シリーズです。ここでは、シリーズ全体の概要、基本ルール、各回の優勝者と関連URLをまとめます。

参加資格：運営が事前に告知した時刻のアジアサーバーレート上位8名。連絡がつかない場合は繰り下げ等を行う。

試合形式：20ptのチェックルール（リミットゲーム数はありません。勝者が決まるまで行います。）

ポイント：1位 7pt / 2位 6pt / 3位 5pt / 4位 4pt / 5位 3pt / 6位 2pt / 7位 1pt / 8位 0pt

同着：同着時の折半はありません。

頂上戦決着：2大会連続で出場し、いずれも優勝した選手を「日本一」とします。称号を授与し、併せて賞金を贈呈します。

本大会の規定は、主として Blizzard Japan 主催「Hearthstone Battlegrounds」大会規定に準拠しています。
