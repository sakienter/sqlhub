スタドレメラトニン杯

大会概要とルール

日程
2026年11月14日（土）22:00
定員
16名（エントリー先着順）

ルール

  • 予選：8名ずつの2卓で各2試合。各卓の合計ポイント上位4名、計8名が決勝へ進出します。
  • 決勝：予選通過者8名で1試合を行います。
  • 順位ポイント：1位 9pt / 2位 7pt / 3位 6pt / 4位 5pt / 5位 4pt / 6位 3pt / 7位 2pt / 8位 1pt
  • 合計ポイントが同じ場合は、1位の取得回数が多い選手を上位とします。
  • 1位の取得回数も同じ場合は、1試合で獲得した最高ポイントで比較します。例：6pt＋2ptと4pt＋4ptは合計8ptですが、最高ポイントが6ptの前者が上位となります。

賞金：予選 各卓1位 1,000円 / 決勝1位 3,000円

主催：Stuntdrake (X)

受付期間：2026年11月8日（日）22:00 ～ 11月14日（土）21:50
