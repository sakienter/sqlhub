予選ルール

対戦形式
1回戦から準決勝まで（最大3回戦）
通過条件
各ステージで2試合を行い、獲得ポイントの合計上位4名が次のステージに進みます。
順位ポイント
1位: 8pt / 2位: 6pt / 3位: 5pt / 4位: 4pt / 5位: 3pt / 6位: 2pt / 7位: 1pt / 8位: 0pt
同点時の扱い
同着によるポイントの折半はありません。合計ポイントが同点の場合は、カウントバック方式を採用して順位を決定します。

決勝ルール（決勝卓：8人）

勝敗条件
16ptチェックルールを採用します。16ptに到達した状態で1位を取ると優勝です。
順位ポイント
1位: 8pt / 2位: 6pt / 3位: 5pt / 4位: 4pt / 5位: 3pt / 6位: 2pt / 7位: 1pt / 8位: 0pt
注意点
同時落ちが発生した場合、ポイントは折半となります。
