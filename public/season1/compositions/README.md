# Season 1 構成画像

各DAYのJPG画像を次の場所へ配置します。

```text
public/season1/compositions/
├── day1/
├── day2/
├── day3/
└── day4/
```

ファイル名は次のとおりです。

```text
alutemu.jpg
matsuri.jpg
seseisei.jpg
thundurus.jpg
yoshiyuki.jpg
arekkusu.jpg
gyan.jpg
jp.jpg
```

例：DAY1のAlutemu選手は `public/season1/compositions/day1/alutemu.jpg` に配置します。

画像がまだ存在しない場合、サイトには「構成画像はまだ登録されていません」と表示されます。
